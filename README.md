# Previsão Meteorológica Computacional com Dados do INMET

Rede Neural de Regressão usando os dados climáticos - INMET 2026

## Introdução
O INMET(Instituto Nacional de Meteorologia) reuniu dados metereológicos referes ao primeiro semestre de 2026(Janeiro - Junho), cobrindo todas as regiões do Brasil em diferentes horários.

A ideia em questão é a partir dessa base de dados, desenvolver uma arquitetura onde será capaz de prever o panorama do clima do dia posterior.

## Escopo de Projeto
Primeiramente irei estruturar o projeto em: Treinamento de redes Neurais e aplicação física.

### Treinamento de Rede Neural

1. Geração do Dataset
2. Estrutura de Treinamento
3. Treinamento
4. Análise

### Aplicação Física

1. Criar uma placa que comporte os sensores usados
2. Criar um sistema de integração com interface web e utilização da Rede Neural
